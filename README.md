# Docker Microservices App 🚀

This project demonstrates a simple multi-container application using Docker Compose.

## 🏗️ Architecture

- Frontend: Nginx
- Backend: Python Flask API
- Containers managed using Docker Compose

## 📦 Tech Stack

- Docker
- Docker Compose
- Python (Flask)
- Nginx

## 🚀 How to Run

```bash
docker compose up -d --build
